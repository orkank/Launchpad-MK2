User Mode Actions

Bind shell, URL, HTTP, app toggle, or AppleScript actions to Launchpad grid pads.

  1. Choose a profile: User 1 (5,8) or User 2 (6,8)
  2. Fill in the action type and fields
  3. Click “Map — then press Launchpad”
  4. On the Launchpad, press a grid pad (not the top row or right column: x=0–7, y=0–7). The action is saved to that pad
  5. To use it later: press User 1/2 to enter the mode, then press the mapped grid pad to run the action
